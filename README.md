# واحي ستوديو (Wahy Studio — Wahy-Transcriber v2.1)

منصة تفريغ وتحرير المحاضرات العلمية الذكية مع الاكتشاف التلقائي للآيات القرآنية والأحاديث النبوية والأذكار وبناء الكابشن المتزامن غير المنقسم.

## أبرز المميزات والتحديثات (v2.1)

1. **تصميم عصري مخصص للجمهور مقسم إلى 4 أقسام رئيسية في شريط علوي مدمج**:
   - **📥 الإدخال والتفريغ (`Input`)**: دعم لصق النص المباشر أو ملفات الترجمة (`.txt / .srt / .vtt`)، روابط يوتيوب (`yt-dlp`)، أو رفع ملفات الفيديو والصوت (`.mp4 / .mp3 / .wav`) مع دعم سحابة Groq API أو المعالج الرسومي المحلي (`faster-whisper`).
   - **🎬 العرض والمتابعة (`Display`)**: عرض متزامن جنباً إلى جنب بين مشغل الفيديو (مع شاشة الكابشن الملون الحي) ونص المحاضرة المنسق المزود بـ **مؤشر تقدم القراءة اللحظي للكلمات** والتمرير السلس.
   - **✍️ التحرير الذكي و FN Studio (`Smart Editor`)**: بيئة تحرير مفصولة ذكياً عن قفزات التمرير التلقائي أثناء التشغيل، تضم:
     - **استوديو إضافة المفقود (`FN Studio`) مع محدد النصوص المظلل**: تحديد أي آية أو حديث أو ذكر فات المحرك عبر النقر على أول كلمة ثم آخر كلمة (مع تظليل بصري حي للمدى `fn-tok-start`, `fn-tok-in-range`, `fn-tok-end`, `fn-tok-hover-preview`) أو عبر التظليل بالماوس، مع اقتراحات تلقائية من القاعدة ومعاينة المتن المشكول وتظليل الكلمات المطابقة، ودعم الروايات العشر، أو الإدراج كـ «خارج القاعدة»، أو الحفظ المباشر في قاعدة الأذكار.
     - **فاحص المقتبسات (`Finding Inspector`)**: تعديل حدود الكلمات (`+1W / -1W`)، تغيير التصنيف، المطابقة مع الرسم العثماني القياسي (`Snap to Canonical`)، أو تغيير المرجع.
     - **محرر النص الكامل ومحرر الكابشن الزمني**: تعديل النص مع الحفاظ الذكي على التوقيت اللحظي للكلمات (خوارزمية LCS)، وتقسيم أو دمج مقاطع الترجمة وإزاحة التوقيت ($\pm 0.1\text{s}$).
   - **📿 القواعد والأذكار (`Datasets & Adhkar Studio`)**: قسم متكامل لعرض وإدارة قواعد البيانات، وبشكل خاص **الأذكار والأدعية** (إضافة ذكر جديد، تعديل مباشر للنص والتصنيف، حذف، بحث وتصفية، استيراد وتصدير `JSON`، ومزامنة السحابة) بالإضافة إلى إدارة المقتبسات خارج القاعدة وتصفح القرآن الكريم وكتب الحديث.
   - **📤 نوافذ منبثقة نظيفة للتصدير والإعدادات**: تصدير المحاضرة (`HTML`, `PDF / Print`, `Markdown`, `TXT`, `JSON`) وتصدير ملفات الترجمة (`.SRT`, `.VTT`, `.ASS`) وتخصيص الأقواس وإعدادات حساسية المحرك.

## طريقة التشغيل

- **عبر المتصفح مباشرة (Text & Subtitle Fast-Path + Local Media)**: افتح `index.html` أو شغّل أي خادم محلي بسيط.
- **مع الخادم الخلفي لتفريغ يوتيوب والملفات الصوتية**:
  - على ويندوز: شغّل `run.bat`
  - على لينكس/ماك: شغّل `./run.sh`
